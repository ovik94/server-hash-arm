# Server Hash Arm

Backend-сервис для автоматизации бизнес-процессов ресторанного холдинга. Обеспечивает интеграцию между системой автоматизации iiko, Google Таблицами, Telegram-ботом и MongoDB.

## Функциональность

- **iiko API** — работа с заказами, меню, бронированиями, клиентами (iikoCloud, iikoServer, iikoWeb)
- **Подарочные карты** — генерация, активация, отправка изображений в Telegram
- **Колесо удачи** — проведение розыгрышей с отправкой результатов
- **Отзывы** — сбор и обработка обратной связи
- **Ежедневные отчеты** — формирование и экспорт отчетов в Google Таблицы
- **Расходы** — учет и категоризация расходов (v1, v2)
- **Денежные потоки** — движение средств, отчетность
- **Контрагенты** — управление контрагентами
- **Обеды** — управление обеденными программами
- **Метрики** — сбор и анализ метрик

## Интеграции

- **iiko** — система автоматизации ресторанов
- **Google Sheets** — экспорт отчетов и данных
- **Telegram Bot** — уведомления и отправка изображений
- **MongoDB** — база данных

## Запуск

```bash
npm install
npm start
```

Требуются переменные окружения:
- `MONGO_LOGIN`, `MONGO_PWD`, `MONGO_HOST`, `MONGO_PORT`, `MONGO_DB` — подключение к MongoDB
- `IIKO_API_LOGIN` — API-логин iiko
- Telegram bot token

По умолчанию сервер запускается на порту 8082.

## Архитектура

```
src/
├── controllers/   # Обработка HTTP-запросов
├── services/      # Бизнес-логика
├── repositories/  # Работа с MongoDB (Mongoose)
├── models/        # Схемы Mongoose
├── routes/        # Определение API-роутов
└── lib/           # Утилиты и внешние API (iiko, Google, Telegram)
```

Стиль: TypeScript, Express.js, REST API, контроллеры-сервисы-репозитории.
